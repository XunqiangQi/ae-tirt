Installation
============

Requirements
------------

- Python 3.9+
- NumPy, SciPy, pandas, PyTorch

Install package (editable mode)
-------------------------------

.. code-block:: bash

   pip install -e .

Install development dependencies
--------------------------------

.. code-block:: bash

   pip install -r requirements-dev.txt

Install documentation dependencies
----------------------------------

.. code-block:: bash

   pip install -r requirements-docs.txt
