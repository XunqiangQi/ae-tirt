Example Workflows
=================

The project provides executable examples:

- ``examples/01_basic_usage.py``: end-to-end synthetic fit and evaluation.
- ``examples/02_simulation_study.py``: reduced simulation study.
- ``examples/03_real_data_analysis.py``: empirical-data template.
- ``examples/04_batch_experiments.py``: multi-study batch launcher.
- ``examples/05_paper_real_data_example.py``: direct run using manuscript real-data files.

Paper-aligned scripts:

- ``scripts/run_all_experiments.py``
- ``scripts/run_real_data_analysis.py``
